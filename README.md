# GPT-3 Landing Page

A fully responsive GPT-3 landing page built using React and pure CSS.

This project follows a component-based architecture where each component has its own CSS file for better structure and maintainability.

---

## 🚀 Live Demo

🔗 **Live Website:**  
https://gpt3-a.netlify.app

---

## 🛠 Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3 (Component-based styling)

---

## 📂 Project Structure

src/
 ├── components/
 │    ├── Navbar/
 │    ├── Header/
 │    ├── Features/
 │    ├── Blog/
 │    ├── Footer/
 │    └── ...
 ├── App.jsx
 └── main.jsx

Each component has its own folder and CSS file.

## ✨ Features

- Fully responsive layout
- Modular component structure
- Clean UI design
- Reusable components
- Organized CSS per component

---

## 📦 Installation

1. Clone the repository:

git clone https://github.com/vattikundalaakhila/gpt3.git

2. Navigate to project folder:

cd gpt3

3. Install dependencies:

npm install

4. Start development server:

npm run dev
